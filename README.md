# S16 Remote Control 📺

لوحة تحكم عربية للرسيفر **S16 PLUS GOLD (Android 9)** من Safari على الآيفون، باستخدام **Termux + ADB** فقط، دون كمبيوتر أو استضافة مدفوعة.

## تشغيل المشروع على الرسيفر

انسخ الأوامر في Termux:

```bash
pkg install python git android-tools -y
git clone https://github.com/sattofsalama-art/s16-remote-control.git
cd s16-remote-control
bash start.sh
```

ستظهر لك **وصلة محلية** واسم المستخدم `admin` وكلمة مرور عشوائية. افتح الوصلة من Safari على الآيفون، مع اتصال الهاتف والرسيفر على نفس شبكة Wi-Fi الخاصة بالمنزل. أبقِ Termux يعمل ما دمت تستخدم لوحة التحكم.

## شرط مهم: تفعيل ADB

تعمل واجهة الويب بعد تشغيل البرنامج حتى إن لم يكن ADB متصلاً، **لكن أزرار الريموت لن تعمل إلا عندما تكون خدمة ADB في الرسيفر قابلة للوصول** عبر `127.0.0.1:5555`.

جرّب من Termux:

```bash
adb connect 127.0.0.1:5555
adb devices
```

إذا ظهرت `Connection refused`، شغّل **ADB over Network / Network debugging** من إعدادات مطور الرسيفر إن كان الخيار متاحاً. **USB debugging وحده لا يضمن عمل ADB عبر الشبكة على Android 9.** لا يوجد ضمان أن الرسيفر يدعم الخيار، ولا تمنح هذه الأداة صلاحيات Root.

## تحديث البرنامج بعد تعديل ChatGPT لملفات GitHub

أوقف الخادم في Termux بـ Ctrl+C، ثم:

```bash
cd ~/s16-remote-control
git pull --ff-only
bash start.sh
```

## الحماية والحدود

- للاستخدام على شبكة Wi-Fi منزلية موثوقة فقط: **لا تفتح المنافذ 8765 أو 5555 للإنترنت**.
- يستخدم تسجيل دخول باسم `admin` وكلمة مرور عشوائية عند كل تشغيل، لكن الاتصال **HTTP غير مشفّر**؛ تجنّب شبكات Wi-Fi العامة.
- الواجهة محدودة بأوامر ريموت مسموحة، إظهار أسماء البرامج، تشغيلها وفتح الإعدادات؛ لا تتضمن تنفيذ أوامر عامة من المتصفح.
- **لا تُنشئ صلاحيات Root ولا تعدّل Firmware ولا تحذف تطبيقات النظام أو ملفات `/system`.**
- GitHub يحفظ الكود وتحديثاته. ChatGPT يستطيع تعديل المشروع من GitHub، لكن لا يدخل جهازك مباشرة دون خدمة تعمل عليه.
- لا ترفع كلمات المرور أو المعلومات الخاصة بالرسيفر إلى المستودع العام.
