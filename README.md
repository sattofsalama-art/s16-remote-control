# S16 Remote Control 📺

لوحة تحكم عربية للرسيفر **S16 PLUS GOLD (Android 9)** من Safari على الآيفون، باستخدام **Termux + ADB** فقط، دون كمبيوتر أو استضافة مدفوعة.

## تحكم بالشاشة دون كتابة أوامر — تطبيق APK

يتضمن المشروع تطبيق Android منفصلاً ضمن `android-app/`، يتم بناؤه تلقائياً بواسطة GitHub Actions إلى ملف `S16-Phone-Remote.apk`. هذا بديل مستقل عن لوحة Termux القديمة.

1. من المتصفح على **الرسيفر**، افتح [صفحة أحدث إصدار APK](https://github.com/sattofsalama-art/s16-remote-control/releases/latest)، واضغط على `S16-Phone-Remote.apk` ثم **Install**. لا تثبّت الـAPK على الآيفون.
2. افتح **S16 Phone Remote** على الرسيفر. اضغط **Allow Remote Touch (Accessibility)**، وفعّل خدمة **S16 Phone Remote Control** يدوياً من إعدادات تسهيلات الاستخدام.
3. اضغط **Start Screen Sharing** ووافق على طلب تصوير الشاشة.
4. افتح **كاميرا الآيفون** وامسح رمز QR الذي يظهر في التطبيق على الرسيفر، وافتح الرابط في Safari. استخدم شبكة Wi-Fi المنزلية نفسها.

تستطيع من Safari رؤية الشاشة (صور متتابعة؛ ليس بث فيديو سريعاً)، اللمس والسحب، الأزرار الأساسية، فتح إعدادات Android والتطبيقات. قد تعود شاشة سوداء لمحتوى فيديو محمي، وقد لا يدعم Android TV بعض حركات اللمس. هذا الحل **لا يمنح Root** ولا يغيّر ملفات النظام المحمية.

**تحذير أمان:** تشغيل الخدمة يسمح بالتحكم الحساس بالجهاز. رمز QR خاص، ولا تشاركه؛ الاتصال HTTP على الشبكة المحلية وليس مشفراً. لا تفتح المنفذ 8766 على الإنترنت أو على شبكة عامة. أوقف مشاركة الشاشة عند الانتهاء.

## تشغيل المشروع على الرسيفر

انسخ الأوامر في Termux:

```bash
pkg install python git android-tools -y
git clone https://github.com/sattofsalama-art/s16-remote-control.git
cd s16-remote-control
bash start.sh
```

ستظهر لك **وصلة محلية** واسم المستخدم `admin` وكلمة مرور عشوائية. افتح الوصلة من Safari على الآيفون، مع اتصال الهاتف والرسيفر على نفس شبكة Wi-Fi الخاصة بالمنزل. أبقِ Termux يعمل ما دمت تستخدم لوحة التحكم.

## شرط مهم: تفعيل ADB

تعمل واجهة الويب بعد تشغيل البرنامج حتى إن لم يكن ADB متصلاً، **لكن أزرار الريموت لن تعمل إلا عندما تكون خدمة ADB في الرسيفر قابلة للوصول** عبر `127.0.0.1:5555`.

جرّب من Termux:

```bash
adb connect 127.0.0.1:5555
adb devices
```

إذا ظهرت `Connection refused`، شغّل **ADB over Network / Network debugging** من إعدادات مطور الرسيفر إن كان الخيار متاحاً. **USB debugging وحده لا يضمن عمل ADB عبر الشبكة على Android 9.** لا يوجد ضمان أن الرسيفر يدعم الخيار، ولا تمنح هذه الأداة صلاحيات Root.

## تحديث البرنامج بعد تعديل ChatGPT لملفات GitHub

أوقف الخادم في Termux بـ Ctrl+C، ثم:

```bash
cd ~/s16-remote-control
git pull --ff-only
bash start.sh
```

## صلاحيات Root على الرسيفر (من دون كمبيوتر)

أضفنا أداة `root-manager.sh` لاختبار صلاحيات `adbd` ومحاولة تفعيلها فقط على أجهزة `userdebug` أو `eng` التي تدعم ذلك. **GitHub لا يمنح Root بحد ذاته.**

من Termux على الرسيفر، أوقف لوحة التحكم مؤقتاً بـ Ctrl+C ثم:

```bash
cd ~/s16-remote-control
git pull --ff-only
bash root-manager.sh check
bash root-manager.sh enable
```

ستطلب الأداة كتابة `ROOT` للموافقة على إعادة تشغيل خدمة ADB بصلاحيات أعلى، وقد ينقطع اتصال ADB إن لم يرجع المنفذ 5555 بعد إعادة التشغيل. إذا نجحت، ستظهر `uid=0(root)`. ثم أعد فتح لوحة التحكم بواسطة `bash start.sh` واضغط **فحص Root الآن** من الآيفون.

عند الانتهاء، **أعد خدمة ADB إلى صلاحياتها العادية** من Termux:

```bash
cd ~/s16-remote-control
bash root-manager.sh disable
```

هذا ليس Root دائمًا باستخدام Magisk أو فتح bootloader، ولا يتيح مباشرة الكتابة في `/system`. يُشترط وجود اتصال ADB مسبقاً، ونجاح محاولة `adb root` ليس مضموناً حتى مع `userdebug`. لا تفتح المنفذ `5555` على الإنترنت: تفعيل Root في خدمة ADB التي تستمع عبر الشبكة يعرض الجهاز لخطر بالغ على الشبكات غير الموثوقة.

## الحماية والحدود

- للاستخدام على شبكة Wi-Fi منزلية موثوقة فقط: **لا تفتح المنافذ 8765 أو 5555 للإنترنت**.
- يستخدم تسجيل دخول باسم `admin` وكلمة مرور عشوائية عند كل تشغيل، لكن الاتصال **HTTP غير مشفّر**؛ تجنّب شبكات Wi-Fi العامة.
- الواجهة محدودة بأوامر ريموت مسموحة، إظهار أسماء البرامج، تشغيلها وفتح الإعدادات؛ لا تتضمن تنفيذ أوامر عامة من المتصفح.
- **لا تُنشئ صلاحيات Root ولا تعدّل Firmware ولا تحذف تطبيقات النظام أو ملفات `/system`.**
- GitHub يحفظ الكود وتحديثاته. ChatGPT يستطيع تعديل المشروع من GitHub، لكن لا يدخل جهازك مباشرة دون خدمة تعمل عليه.
- لا ترفع كلمات المرور أو المعلومات الخاصة بالرسيفر إلى المستودع العام.
